# Figures

Generated by `python -m conflict_eval analyze --config configs/pilot.yaml`
from real result files in `results/` only (see
`src/conflict_eval/analysis/plots.py`). The analysis code refuses to plot
from empty or synthetic-only input rather than producing placeholder
figures.

Four figures are produced, matching `docs/phase2_research_design.md`:

1. `plot1_signature_interaction.png` — context adoption vs. parametric
   margin, split by source role and evidence truth.
2. `plot2_corrective_vs_harmful.png` — 2x2 override-rate summary.
3. `plot3_condition_summary.png` — C0-C4 rates by model and knowledge
   group.
4. `plot4_abstention.png` — abstention rate under conflict (exploratory).

## Status

As of this writing, no real pilot has been run, so this directory contains
no figures yet.
